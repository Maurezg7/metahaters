# metahaters

Índice global ultra ligero y autoactualizable para hackathons: modelos AI, APIs gratis y pagas, lenguajes, frameworks por área, sistemas operativos/distros, navegadores seguros y livianos, agentes/sub-agentes descargables, comandos multi-agente A2A, divisas en vivo, estándares crypto y War Room con noticias dev.

## Uso local

```bash
python3 -m http.server 4173
```

## Actualización del catálogo

```bash
node scripts/update-catalog.mjs
```
